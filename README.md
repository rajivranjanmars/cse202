# CSE202 C++ Coursework

C++ classroom exercises covering classes, constructors, functions, arithmetic, and other introductory programming concepts. Files are organized by lesson date or exercise.

## Usage

Choose a source file and compile it separately with a C++ compiler. These are independent learning exercises rather than a single application; some examples deliberately demonstrate incomplete or invalid constructs.
